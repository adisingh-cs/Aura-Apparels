# 🛍️ AURA APPARELS – E-Commerce Platform

Welcome to the official repository for **AURA APPARELS**, a modern and minimalist e-commerce web application focused on selling Gen Z-friendly apparel.

## 🚀 Overview

AURA APPARELS is an online clothing store built using Django. It offers a user-centric interface for customers to browse and shop products like T-Shirts, Hoodies, Polo T-Shirts, and more. Admins can easily manage products and orders through a dedicated dashboard.

---

## 📌 Features

### 👤 Customer Features
- Sign Up / Login / Logout
- Browse products with images and details
- Filter & search by product/category
- Add/remove items to/from cart
- Checkout with PDF receipt download
- Track order statuses (Pending → Delivered)
- View and download past order receipts
- Fully responsive UI with dark mode toggle 🌙

### 🔐 Admin Features
- Product management (Add/Update/Delete)
- Inventory tracking
- Order status updates
- Dashboard with sales/users/orders stats
- Export data to Excel (Orders, Users, Sales)

### 🎨 Design & UI
- Clean and minimal design
- Gen Z color palette (Violet, Pink, White, Blue)
- Google Fonts: Roboto, Poppins
- Bootstrap components (if needed)
