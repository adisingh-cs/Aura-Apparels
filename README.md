# 🛍️ AURA APPARELS – E-Commerce Platform for Gen Z Fashion

Welcome to the official repository of **AURA APPARELS**, a modern and minimalist e-commerce web application tailored for Gen Z. Developed as a side venture alongside academics, this platform is a testament to full-stack Django proficiency, real-world product design, and entrepreneurial initiative.

🔗 [Live Project – AURA APPARELS](https://eternalshub.wixsite.com/aura-shop)

---

## 🚀 Overview

**AURA APPARELS** is a full-stack e-commerce solution built using Django, offering a sleek and mobile-optimized interface for browsing and purchasing youth-centric fashion items. From user authentication and product filtering to downloadable receipts and admin analytics, the platform delivers a comprehensive online shopping experience.

This project not only showcases my technical ability in Django, HTML/CSS, and JavaScript, but also demonstrates strategic thinking in branding, UI/UX, and product management — all self-built while managing multiple ventures.

---

## ✨ Key Features

### 👤 Customer Experience
- User Sign Up, Login, Logout
- Browse curated apparel (T-Shirts, Hoodies, Polos, etc.)
- Search and filter by category or name
- Add/remove products to/from cart
- Checkout with downloadable **PDF receipt**
- Order status tracking (Pending → Delivered)
- View order history and past receipts
- Mobile-first, responsive design with **dark mode** 🌙

### 🔐 Admin Dashboard
- Secure Django admin panel
- Product management (Add / Edit / Delete)
- Update order statuses
- Track sales, users, and inventory
- Export order/user/sales data to **Excel**

### 🎨 UI & Branding
- Clean, minimalist design system
- Gen Z-inspired color palette: Violet, Pink, White, Blue
- Google Fonts: **Roboto**, **Poppins**
- Responsive components via **Bootstrap** and **FontAwesome**
